Dossier des images de MyWebPlace
=================================

Placez ici vos visuels : logo, photos d'équipe, captures de réalisations, etc.

Le site fonctionne sans images réelles : les visuels de la maquette
(hero, vignettes de projets, médaillons statistiques) sont générés en
CSS pur (dégradés + emojis) pour rester légers et 100 % responsives.

Recommandations :
- logo.svg / logo.png ......... logo de la marque
- favicon.ico / favicon.png ... icône d'onglet
- og-image.jpg (1200x630) ..... aperçu pour les réseaux sociaux
- realisations/ ............... captures de vos projets clients

Formats conseillés : SVG pour les logos/icônes, WebP ou JPEG optimisé
pour les photos. Pensez à compresser les images avant la mise en ligne.
